# 3D Model Directory

Place the `room.glb` file generated by the Google Colab pipeline here.

## How to Get `room.glb`

1. Open `pipeline/Namma_Space_Colab_Pipeline.ipynb` in Google Colab (T4 GPU runtime).
2. Upload your smartphone walkthrough video (`.mp4`) when prompted.
3. Run all 4 cells sequentially.
4. The pipeline will auto-download `room.glb` when complete.
5. Move the downloaded `room.glb` into this directory: `public/models/room.glb`.

## Alternative: In-Browser Hot-Swap

You can also load any `.glb` / `.gltf` file directly in the web viewer without placing it here:

1. Open the web viewer (`index.html` or the Netlify URL).
2. Click the **"Load .GLB Model"** button in the top-right HUD.
3. Select your `.glb` file from your device's file picker.
4. The model loads instantly in the browser — no redeployment required.

> **Note:** If no `room.glb` is found in this directory, the web viewer automatically generates a stylish procedural demo room so the app is 100% playable out-of-the-box.
